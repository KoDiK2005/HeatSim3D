# HeatSim3D
Практика для НИРа
-------------------
Программный комплекс для математического моделирования теплопередачи в сплошных 
средах. Реализует явную конечно-разностную схему FTCS для решения трёхмерного 
уравнения теплопроводности Фурье–Кирхгофа на равномерной декартовой сетке. 
Поддерживает независимые граничные условия Дирихле на каждой из 6 граней области, 
выбор материала из библиотеки твёрдых тел и визуализацию результатов в виде 
тепловых карт, изолиний и профилей температуры.

Графики для отчёта
------------------
`report_plots.py` строит рисунки в «журнальном» стиле (белый фон, чёрные
линии, серая сетка, шрифт с засечками, подпись «Рисунок N — ... (а) ... (б)»):

```
python report_plots.py output --num 3.5 --fmt png pdf     # T(t) и профили T(x), T(y)
python report_plots.py --bench --exe heat3d.exe --threads 1 2 4 8 --nx 80 --num 3.7
                                                          # время и ускорение OpenMP
```

Рисунки сохраняются в `output/report/` (или `bench/output/report/`).
В GUI то же самое делают кнопки «Графики для отчёта» и «Замер ускорения OpenMP».

`heat3d` принимает `--threads N` (число потоков OpenMP) и пишет `output/params.csv`.
Сборка с OpenMP: `g++ -O2 -fopenmp -std=c++17 heat3d.cpp -o heat3d.exe`
(Visual Studio: C/C++ → Язык → Поддержка OpenMP → Да, `/openmp`).
